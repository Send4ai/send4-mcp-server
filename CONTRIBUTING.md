# Contributing

Thanks for helping make these guides better.

- **A step that's wrong or out of date** (an assistant moved a menu, a label changed): open a pull
  request with the fix, or an [issue](https://github.com/Send4-ai/mcp/issues/new/choose) that says
  which guide and what you saw.
- **Something an assistant should be able to do in Send4:** open an issue with the **Idea** form.
- **A security problem:** never in an issue or a pull request. See [SECURITY.md](SECURITY.md).

This repository holds documentation and client configuration only. The server isn't here, so a
pull request can't change what a tool does.

Issues and pull requests are public. Never include access tokens, passwords, or your customers'
messages, names, phone numbers or email addresses.
